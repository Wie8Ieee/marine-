# Canonical experiment artifacts

This directory is the organizational index for final canonical experiment evidence.
Original files remain in their source locations; historical artifacts are indexed only
and are excluded from the final comparison. A checkpoint is canonical only after its
config, dataset provenance, environment, history, and artifact verification pass.

The active protocol uses validation mAP@0.5:0.95 to select `best` checkpoints.
Trash Test and River evaluation are prohibited until all three model runs pass artifact
verification. Paper tables must use verified canonical evaluation outputs only.
